# Mobile Sales Dashboard – Power BI

An interactive Power BI dashboard analyzing mobile sales data from 2021 to 2024.

## 📊 Dashboard Preview

![Mobile Data Dashboard](Mobile%20Data%20Dashboard.jpg)

## 🔢 Key Metrics

- **Total Sales** : 769.2M  
- **Total Quantity Sold** : 19K  
- **Total Transactions** : 3.8K  
- **Average Price** : 40.1K  

## 📈 Visualizations Included

- **Sales by Brand** : Apple, Samsung, OnePlus, Vivo, Xiaomi  
- **Sales by Mobile Model** : iPhone SE, OnePlus Nord, Galaxy Note 20, Vivo Y51, Galaxy S21, iPhone 11, Galaxy A51, iPhone 12, Vivo V20, Mi 11  
- **Sales by Payment Method** (with % share)  
- **Total Quantity by Year** : 2021–2024  
- **Geographic Map** : Sales across Asia, Europe, North America, South America, Africa, Oceania  

## 🛠 Tools Used

- Power BI Desktop  
- Data source : Mobile sales dataset (2021–2024)

## 📁 Files in this Repository

- `Mobile.pbix` – Main Power BI report  
- `Mobile Data Dashboard.jpg` – Dashboard screenshot  
- Other `.pbix` and image files for additional dashboards

## 🚀 How to Use

1. Download `Mobile.pbix`  
2. Open with **Power BI Desktop** (free from Microsoft)  
3. Explore filters – click on any chart to cross-filter the dashboard
